# Conserjería virtual (React + CSS)
Tótem de conserjería "seguritech.cl" generado desde el prototipo de Figma (Conserjería diseño crítico).
    npm install && npm run dev      # servidor local en http://localhost:5173
    npm run build                   # genera dist/index.html (archivo único)
- `src/data.js`: todas las pantallas y conexiones del prototipo. `src/components/`: Pill, Label, Keypad, Checkbox, HelpButton, Background, Screen.
- Lienzo fijo 1366x1024 escalado al tamaño de la ventana (responsive).
